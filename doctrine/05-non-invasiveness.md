# Doctrine 05 — Non-Invasiveness

Upstream tooling has broken real projects: an added detector caused an infinite
recompile loop, unbounded history made an operation 13× slower, and a shipped
`package.json.meta` GUID collided with another tool and produced project-wide
"missing script" warnings. This doctrine prevents all three classes of harm.

## 1. Principle

- The agent may read anything.
- It may write only what the task requires.
- It MUST NOT leave the project in a state the user did not ask for.

## 2. Forbidden by default

| Forbidden | Why |
|---|---|
| Auto-running editor hooks (`[InitializeOnLoad]`, `[InitializeOnLoadMethod]`) | run on every domain reload; a detector once caused an infinite recompile loop |
| Presence or idle detectors | background work the user never triggered |
| File watchers that trigger recompiles | every write re-imports the project |
| Background daemons | outlive the task and own the machine |
| Telemetry, analytics, crash reporting, phone-home | sends data with no opt-in |
| Global Unity/Hub preference edits | changes the user's machine, not the project |
| Writing outside the project | leaves traces the user cannot see or undo |
| Stray files under `Assets/` | pollutes the project and its GUID space |
| Silent `ProjectSettings` changes (render pipeline, physics, input, quality) | alters behaviour the user chose |
| Silent package version changes | breaks reproducible builds |

If a check seems valuable, expose it as an explicit command the user or the
agent invokes. Never ship a default that runs by itself.

## 3. Nothing ships into the user's project by default

- No Unity packages, `.asmdef`, `.meta`, prefabs, or assets in this repository.
- Nothing here executes inside the user's Editor unless the user explicitly runs it.
- A future helper package (see `docs/01-product-idea.md` §10) must be opt-in, namespaced, and GUID-registry-checked.

## 4. Where writes belong

| Path | Rule |
|---|---|
| `Assets/`, `Packages/`, `ProjectSettings/` | write only what the task requires; leave no leftovers |
| `Library/`, `Temp/`, `Logs/`, `obj/`, `Build/`, `UserSettings/` | regenerated by Unity — never commit, never hand-edit |
| Repo files under `docs/`, `doctrine/`, `skills/` | touch only files the user named |
| Anywhere outside the project | only with explicit approval (see `doctrine/01-safety.md` §4) |

## 5. Bounded state

- Any cache, history, undo, or log a tool keeps must have a fixed bound and a documented eviction policy.
- Unbounded growth is a defect, not a feature.

## 6. No ambient side effects

- Compiling, importing, recompiling, or reimporting must happen only as a deliberate step, never as a side effect of merely reading.
- Reading state must be free of cost and side effects.

## 7. Reversibility contract

- Prefer the reversible path: new file over overwrite, branch over commit, additive over in-place (see `doctrine/01-safety.md` §8).
- Every change MUST be revertible and reviewable as a diff.
- State the undo path with the action (see `doctrine/01-safety.md` §10) before making the change.

## 8. "Leave it better" is bounded

- The agent MUST NOT reformat, rename, or restructure files it was not asked to touch.
- Such cleanups are review requests, not silent changes: report them and let the user decide.

## 9. Tooling performance budget

Tooling must not measurably slow the Editor:

- No per-frame editor work while idle.
- No recompiles triggered by reads.
- Any recurring task states its frequency and its measured cost.

## 10. Collision discipline

Before referencing a Unity package, asset GUID, layer, tag, input action map, or
scripting define, check for an existing definition and reuse it. Namespace
anything new with the project prefix. When in doubt, do not add — compose.

## 11. The test

Would this change surprise a developer who opens the project tomorrow and does
not know about us? If yes, do not make it.

## 12. Non-invasive by default — finish checklist

| # | Check |
|---|---|
| 1 | No temp, scratch, or backup file left in the project |
| 2 | No `ProjectSettings` value changed that the task did not require |
| 3 | No orphan file, `.meta`, or folder under `Assets/` |
| 4 | No package added or version changed |
| 5 | No hook, watcher, or background process left running |
| 6 | No global Unity or Hub preference touched |
| 7 | Every changed file is named in the summary, with its undo path |
| 8 | The project still opens and compiles clean |
